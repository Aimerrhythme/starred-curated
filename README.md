# starred-curated

一份按主题整理的 GitHub Star 学习笔记。把以后还会再打开的开源仓库收成可检索的卡片，而不是一张只增不减的收藏列表。

两条主线：

- **AI / 开发工具**：模型应用、Agent、编辑器，以及日常会用到的工程化工具
- **电气 / 电力相关开源**：电力系统、能源物联网，以及和机器学习结合的实现

分类页只做索引。每座仓库的适用场景、最小用法和留下的理由，写在 `entries/OWNER-REPO.md`。

## 每周怎么更新

默认每周整理一次。当周没有值得留下的仓库，也在变更记录里写明「无新增」，避免和漏更新混在一起。

1. 从本周读过、用过的仓库里挑选：能讲清适用场景，并且自己还会再打开一次。
2. 按 [条目约定](docs/entry-convention.md) 新建 `entries/OWNER-REPO.md`。
3. 在对应分类表追加一行：仓库、一句话简介、入库日期、详情链接。
4. 把日期和变更写进 [CHANGELOG.md](CHANGELOG.md) 顶部。

每周三下午（Asia/Shanghai）由策展自动化挑选：一半看近期 Star 激增的仓库，一半看长期维护、口碑稳定的仓库；入库的同时会在 GitHub 上真实点亮 Star。条目里的「是否已 Star」记录当时的事实，随时可以手动取消。

## 声明

本仓库是**教辅和学习笔记**，记录个人阅读与试用时的理解。

- 不是上游官方文档。命令、接口、许可证以源仓库当前版本为准。
- **不是背书**。入库不表示推荐用于生产、安全或合规场景，也不代表项目维护者的立场。
- 笔记中的用法是便于回忆的最小例子，可能随上游版本失效。
- 「是否已 Star」只描述个人账号上的状态，不表示推荐强度。
- Star 数、许可证等数字取自入库当天的 GitHub API，之后不会自动更新。
