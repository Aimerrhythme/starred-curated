# logisim-evolution/logisim-evolution

## 简介

数字逻辑电路的画图与仿真：门电路、组合逻辑和时序电路可以在软件里搭完，再看波形。

## 适用场景

- 适合：数电实验里做组合电路、触发器、简单时序；实验箱不够，或课前预习。
- 不适合：模拟电路，或要和 FPGA 工具链对时序签核结果。它是原理图级仿真。

## 快速用法

从 Releases 下载安装包或 jar：https://github.com/logisim-evolution/logisim-evolution/releases

Windows、macOS、Linux 的安装包自带 Java 运行时。若用 `logisim-evolution-<version>-all.jar`，本机需要 Java 21 或更新。选哪个包见上游 README 的 Download 一节（2026-10-28）。
